# Third-party notices

Riffroad builds on the open-source projects below. Their licences apply to their code; the
full texts come with each package (`app/node_modules`, `~/.cargo/registry`, the Python
environment).

## Shipped inside the app

| Component | Licence | Use |
|---|---|---|
| [Tauri](https://tauri.app) and its plugins | MIT or Apache-2.0 | desktop shell |
| [three.js](https://threejs.org) | MIT | note highway and stage (3D) |
| [Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch), [Teko](https://fonts.google.com/specimen/Teko), [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (via Fontsource) | SIL Open Font License 1.1 | interface fonts |

The MPL-2.0 crates are used unmodified; their source is on [crates.io](https://crates.io).

The note detector's weights (`engine-rt/dsp/assets/notenet.bin`) were trained on pieces
Riffroad composes and plays on single notes recorded in **Guitar-TECHS** (Hegel Pedroza,
Wallace Abreu, Ryan M. Corey and Iran R. Roman, "Guitar-TECHS: An Electric Guitar Dataset
Covering Techniques, Musical Excerpts, Chords and Scales Using a Diverse Array of Hardware",
2025, [guitar-techs.github.io](https://guitar-techs.github.io)), licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The recordings themselves are not
shipped.

## Installed on the player's Mac on the first import

The song converter (`pipeline-ingest`) is not bundled with its dependencies: on the first
import, `uv` downloads them from PyPI onto the player's Mac.

| Component | Licence | Use |
|---|---|---|
| [Demucs](https://github.com/facebookresearch/demucs) (`htdemucs_6s` model, downloaded on first use) | MIT | stem separation |
| [Basic Pitch](https://github.com/spotify/basic-pitch) (model included) | Apache-2.0 | guitar transcription |
| [PyTorch](https://pytorch.org) | BSD-3-Clause | runs Demucs |
| [librosa](https://librosa.org) | ISC | onsets, beat tracking |
| NumPy, SciPy, scikit-learn, soundfile | BSD | signal processing, audio files |
| [PyGuitarPro](https://github.com/Perlence/PyGuitarPro) | LGPL-3.0 | Guitar Pro import |
| [PyYAML](https://pyyaml.org) | MIT | feedpak import (manifests) |
| python-soxr, lameenc | LGPL-2.1+ / LGPL-3.0 | resampling, MP3 (via Demucs) |
| jsonschema, mir_eval, pretty_midi, julius, einops | MIT | chart validation, transcription tooling |
| certifi, tqdm | MPL-2.0 | downloads |

madmom is **not** used: its pretrained models are licensed CC BY-NC-SA 4.0. Beats come from
librosa and Riffroad's own code.

## Tools the player installs

[uv](https://github.com/astral-sh/uv) (MIT or Apache-2.0), [FFmpeg](https://ffmpeg.org)
(LGPL-2.1+ / GPL depending on the build). Riffroad runs them as separate programs and does
not distribute them.

## Content

The demo song "First Riff" is generated by Riffroad's own code (`opensmith-ingest demo`) and
is covered by Riffroad's licence.

Four rock songs ship with the app (`app/demo/Shane Ivers - …`), each licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/):

- Music: Hard Sell Hotel by Shane Ivers - https://www.silvermansound.com
- Music: Apple For The Preacher by Shane Ivers - https://www.silvermansound.com
- Music: Later Alligator by Shane Ivers - https://www.silvermansound.com
- Music: Wave Rider by Shane Ivers - https://www.silvermansound.com

Changes made: each recording was split by Riffroad's song pipeline into the band without its
guitar (`backing.ogg`) and the guitar alone (`guitar.ogg`), both re-encoded in Ogg Vorbis, and
its guitar parts were charted from it (`song_chart.json`, `song_chart.chords.json`). The
originals are on silvermansound.com.
